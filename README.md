# Step-Progress-Widget

Componente de progresso por etapas desenvolvido em React e Vite.

Projeto desenvolvido para fins educacionais.

## Onde está o código

Interface em `src/App.jsx`.

**Tecnologias:** `CSS`, `HTML`, `JavaScript`, `React`, `Vite`.

## Demonstração

[Acessar projeto](https://rafael-m-silva.github.io/Step-Progress-Widget/)

## Executar localmente

```bash
npm install
npm run dev
```
